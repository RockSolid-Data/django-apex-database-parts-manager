How it works
  1. Upload the PDF — the parser reads every entry (bold YT number + description + interchanges) from all pages.
  2. Preview the parsed data. You can change the Category for any row before importing, and review any flagged rows that need a closer look.
  3. Confirm — parts are created or updated, and all interchange source/name plus reference number pairs are saved to the Interchange section of each part. The bold PDF number is stored in YT Number only, not Part Number.

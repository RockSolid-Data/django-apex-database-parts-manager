CSV Format Tips

Item Number is optional. If your CSV includes it, existing parts with the same number will be updated. If it's missing, new parts will be created automatically.

The Category column sets the Part Category (e.g. "Brushes", "Bearings"). Different categories can be mixed in one file.

Any column that doesn't match a recognised field is stored as a custom specification for that part.

Use Unit Number to link a part to an existing unit.

Common column name variations are recognised automatically (e.g. "Part #", "J&N Number", "Manufacture", "Unit Type").
